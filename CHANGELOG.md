# Changelog

## 0.3.0

- Hybrid discovery with autocomplete, adaptive filters, creator and character associations.
- Music edition grouping and resilient mixed-source album previews; selected editions control track listings.
- Creator profiles and catalogs, richer media-specific details, artwork galleries, and display preferences.
- Parent-owned episode, season, song, collection, chapter, volume, and page completion.
- Library shelves, insights, custom ordering, ratings, profile, and Grid/List/Text views.
- Forest, Dark, and classic Yotsuba presentation; configurable motion and navigation.
- Safer identity handling and personal-data preservation regressions.

Validation: all 21 frontend test suites and JavaScript syntax checks. Live album/artist/developer smoke checks and three-theme visual checks passed.

Deploy alongside folio-metadata-api v0.3.0. Libraries remain browser-local; export before changing origin. No accounts or synchronization are included.
